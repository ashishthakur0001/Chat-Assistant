# Chat-Assistant

A Retrieval-Augmented Generation (RAG) chatbot that answers questions from PDF documents using GROQ LLM and ChromaDB.

## Features

- PDF Upload
- Semantic Search
- Vector Embeddings
- GROQ LLM Integration
- Conversational AI
- Chainlit UI

## Run Project

```bash
chainlit run app.py
---

# 🚀 Running the Project

## Step 1

Clone the repository

```bash
git clone https://github.com/your-username/Chat-Assistant.git
Step 2

Install dependencies
pip install -r requirements.txt
Step 3

Add GROQ API key inside .env
GROQ_API_KEY=your_key
Step 4
run the project
chainlit run app.py
